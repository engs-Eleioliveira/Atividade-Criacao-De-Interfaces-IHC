Acessibilidade

Acessibilidade é criar interfaces que possam ser percebidas, entendidas e usadas por todas as pessoas, com diferentes corpos, sentidos e formas de navegar.

IncluirPerceberParticipar
Aa◉⌨▶

Uma interface para todas as pessoas

A acessibilidade faz parte do projeto desde o começo. Abra os cartões para ver atitudes práticas.

1Perceptível

Oferecer texto alternativo, legendas, contraste adequado e mais de uma forma de perceber uma informação.

2Operável

Permitir que tudo funcione pelo teclado, sem depender apenas de mouse, toque ou movimentos precisos.

3Compreensível

Usar linguagem clara, navegação previsível e mensagens que ajudem a corrigir erros.

4Compatível

Construir com HTML semântico para funcionar com leitores de tela, navegadores e tecnologias assistivas.

5Contraste

Garantir que textos e controles possam ser identificados mesmo por quem tem baixa visão ou está em uma tela com pouco brilho.

6Respeito

Não usar acessibilidade como barreira: dar tempo, escolha e controle para cada pessoa concluir sua tarefa.

Acessibilidade não é um recurso extra. É uma condição para participar.

Quando removemos barreiras, mais pessoas conseguem fazer parte da experiência.

Na prática

Pequenas escolhas, grandes diferenças

Antes de publicar uma interface, observe se cada pessoa tem um caminho possível para encontrar informação e realizar sua tarefa.

  • ✓ Foco visível ao navegar pelo teclado
  • ✓ Botões com nomes que explicam sua ação
  • ✓ Imagens importantes com descrição
  • ✓ Vídeos com legendas e controles claros

Interface inclusiva

  • O campo tem um nome claro (semântica)
  • O foco mostra onde a pessoa está (teclado)
  • A instrução explica como interagir (clareza)

Barreiras desnecessárias

  • Ícone sem nome acessível (leitor de tela)
  • A ação depende do mouse (navegação)
  • Não há orientação para continuar (compreensão)
